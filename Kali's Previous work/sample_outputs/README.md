# Pipeline Sample Outputs

This directory contains intermediate and final outputs generated from testing and running the YADEP pipeline on target YouTube videos.

## Files

- **`audio.mp3`**: A sample raw or processed audio file extracted from a YouTube video.
- **`transcript.json`**: Full structured transcript generated by the transcription engine containing text segments, speakers, and timing data.
- **`transcript.txt`**: Verbatim plain text transcript output.
- **`transcript_timestamps.txt`**: Plain text transcript showing start and end timestamps for each speech segment.
- **`example.md`**: An example markdown file containing a formatted view of the transcript segment.
