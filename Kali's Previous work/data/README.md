# Dataset Chunks and Manifests

This directory contains the structured metadata and indexes used for the agricultural outreach audio dataset.

## Files

- **`YT_DATASET.csv`**: The initial compilation of YouTube video metadata (video IDs, titles, descriptions).
- **`FINAL_VIDEO_MANIFEST.csv`**: The finalized manifest of YouTube video URLs and IDs chosen for processing.
- **`VERIFIED_AUDIO_INDEX.csv`**: Index mapping verified downloaded audio files and their verification status.
- **`FINAL_ML_TRAINING_CHUNKS.csv`**: The final split/segmented metadata showing individual audio chunks (start/end timestamps, duration, clean transcribed text) formatted for machine learning training.
