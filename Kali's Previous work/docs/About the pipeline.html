The Problem Statement
01 / 07

Compiling Punjabi Agricultural STT Corpora

Building high-fidelity Automatic Speech Recognition (ASR) datasets for agricultural outreach programs (e.g., Krishi Darshan) poses unique operational challenges:

Rate Throttling & Blocks

Scraping and downloading large-scale video/audio playlist assets directly from YouTube frequently triggers platform rate blocks and IP bans.

RAM Crashes & Resource Limits

Transcribing continuous hours of audio in a single pass exhausts GPU VRAM and system memory, leading to kernel crashes and execution failures.

Main Pipeline: YADEP.ipynb
02 / 07

Batch Ingestion & Local Whisper ASR

Our initial automated batch ingestion workflow combined yt-dlp, ffmpeg, and a local Whisper Large V3 engine.

Pipeline Phase Technical Execution Details
Ingestion & Slicing Downloads video audio streams via yt-dlp and slices them into uniform 30-second segments to guard local RAM.
Local Transcription Ingests 30s segments locally to run Whisper Large V3 ASR decoding.
Transcription Evaluation Unsatisfactory Results: Transcripts suffered from severe repeating loops and stutters (e.g. repeating words like "प्रस्तुत" and "चूला" indefinitely).
Helper Notebook: Interactive Downloader

Pivot to Remote Gemini API

To bypass local RAM crashes and Whispers repetition loops, we shifted to the remote Gemini File API.
