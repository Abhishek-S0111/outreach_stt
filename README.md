# outreach_stt
This repo is for creating a workflow that captures audio from outreach program and extracts text and questions

## How To Use

### TO run the Node App
```bash
1. Move to /outreach_stt/App/Application
2. Run `npm install` to install dependencies
3. Move to /outreach_stt/App/Application/mic-recorder
4. Run `npm start` to start the local web server which serves `index.html`
```
